# NeuroTrace

## Project objective

NeuroTrace is an educational prototype combining
Artificial Intelligence and Blockchain for brain MRI
image analysis and secure traceability.

## Main features

- Brain MRI image upload
- Image preprocessing
- AI-based tumor classification
- Prediction validation
- Grad-CAM visualization
- SHA-256 hashing
- Hyperledger Fabric registration
- Data integrity verification
- Case history and traceability

## Technologies

- Python
- PyTorch
- OpenCV
- FastAPI
- Angular
- PostgreSQL
- Hyperledger Fabric
- Docker

## Architecture

Frontend -> Backend -> Agent Orchestrator
|
AI / Validation / Explainability
|
SHA-256 / Blockchain
|
Off-chain Storage
